# Ranking

Deployments down the side, one metric across. **A table and two paragraphs.**

## The table

Top 10 by the metric, unless the directive asked for a different number. The metric, plus a second
column where one makes it readable — usually borrows next to deposits.

Every number is a `{fact:ID}` placeholder. You never type a figure.

## The two paragraphs

Roughly 150 words together. **Interpretation, not description** — the table already gives the
numbers, so a sentence that reads one back is a wasted sentence.

1. **What the data shows.** What is largest, how wide the spread is, what stands out.
2. **What is worth knowing.** A figure that is not comparable to the ones beside it, a deployment
   that has wound down, a number that looks wrong.
