ALPHA MARKETS — STANDALONE HTML REFERENCES

Start by double-clicking console.html in your browser.

console.html: homepage with report and wider Atlas console; tokenization below.
reports.html: report marketplace.
markets.html: all predictions, linked to the matching prediction detail files.
prediction-*.html: six individual prediction pages, each with its colored chart and staking panel.
tokenization.html: tokenization section as its own reference page.

Every HTML file contains its own CSS, embedded fonts and inline SVG icons/charts. No install, server, external asset or internet connection is required. Files can be copied independently. Keep them together for the navigation links to work.

These are presentation references, exported from the actual React components. Inputs are visible, but app actions (tabs, report editing, searches, wallet, publishing, payment and staking) are not connected. A small inline script fits the report and console to the screen; it does not perform transactions. Charts preserve the sample series as solid-color SVG lines; hover tooltips and live updates are not included.

To use with another project, provide the relevant HTML file as a visual/code reference. The original source ZIP remains the version for full application behavior. No changes were made to the hosted site.

Embedded fonts: Nimbus Roman and Nimbus Sans (URW Base35). See FONT-LICENSE.txt.
